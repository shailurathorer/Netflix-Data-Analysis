# Netflix Data Analysis Project

## Project Overview

This project analyzes Netflix dataset using Python and data visualization libraries to understand trends, content distribution, ratings, and release patterns.

## Tools & Libraries Used

* Python
* Pandas
* NumPy
* Matplotlib
* Seaborn

## Objectives

* Clean and analyze Netflix dataset
* Explore movie and TV show trends
* Visualize ratings and content distribution
* Find insights from the data

## Key Analysis Performed

* Data Cleaning
* Handling missing values
* Content type analysis
* Rating analysis
* Release year trends
* Visualization using charts and graphs

## Project Insights

* Movies are more common than TV shows
* Most content was released after 2015
* Certain ratings appear more frequently
* Netflix content increased rapidly in recent years

* Netflix_Analysis.ipynb
